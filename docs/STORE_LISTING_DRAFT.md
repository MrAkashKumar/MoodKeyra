## Short description

Choose a mood theme and type privately with a lightweight offline keyboard.

## Full description

MoodKeyra is a private Android keyboard with manually selected mood themes.

Choose Happy, Excited, Calm, Sad, Angry, Thoughtful, Romantic, or Normal, then type normally in messages, social apps, email, notes, and other Android text fields.

Privacy is part of the design:

- Works offline
- No account
- No advertising
- No analytics or tracking
- No Internet permission
- No typed-text storage
- No automatic emotion detection

MoodKeyra sends ordinary text to other applications. WhatsApp, Messages, Instagram, Messenger, Telegram, and other apps control how their own message bubbles look, so MoodKeyra does not claim to change fonts or colors inside those apps.

Android requires every third-party keyboard to be manually enabled. MoodKeyra provides a guided setup screen and a permanent keyboard-switch control so users remain in control.

## Reviewer instructions

1. Install and open MoodKeyra.
2. Tap **Set up MoodKeyra**.
3. Enable **MoodKeyra Keyboard** in Android input-method settings.
4. Return and choose MoodKeyra from the system keyboard picker.
5. Tap the test field or open any standard text field.
6. Select moods from the strip and verify standard typing, Shift, Backspace, Space, symbols, Enter, and the `◎` keyboard switcher.
7. Disable network connectivity and verify the keyboard remains functional.

Android's warning when enabling a third-party input method is expected system behavior.
