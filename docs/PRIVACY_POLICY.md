MoodKeyra is an offline Android keyboard. The user manually selects a visual mood and types normally.

## Data collection and sharing

This version of MoodKeyra does not collect, transmit, sell, share, or retain personal information or typed content. It has no account system, server, analytics, advertising, tracking, crash-reporting, or third-party data SDK.

## Typed content

Key presses are sent directly to the text field currently selected on the device through Android's input-method framework. MoodKeyra does not store typed text, read surrounding text, inspect conversation history, infer emotion, or upload keyboard input.

## Local preferences

MoodKeyra stores only the mood manually selected by the user and whether that mood should reset after one message. These preferences remain in the app's private device storage and are excluded from cloud backup and device transfer.

## Permissions

MoodKeyra does not request Internet, contacts, SMS, call log, microphone, camera, location, storage, notification, advertising ID, package visibility, or accessibility-service permission. Android grants the protected `BIND_INPUT_METHOD` capability to the keyboard service so the operating system can connect it to text fields.

## Children

MoodKeyra does not knowingly collect personal information from anyone, including children, because it does not collect personal information.

## Changes

If MoodKeyra's behavior changes, this policy and the Google Play Data safety declaration must be updated before the changed version is distributed.
